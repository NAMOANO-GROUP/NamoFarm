# Logo NamoFarm

Placez ici le logo de l'application, nommé exactement :

    namofarm.png

Recommandations :
- Format PNG carré, 1024 x 1024 px
- Fond transparent (ou plein)

Ensuite, depuis le dossier `mobile/`, générez les icônes Android/iOS :

    flutter pub get
    dart run flutter_launcher_icons

Le logo s'affichera automatiquement sur l'écran de connexion.
